Product overview

Build email templates from a component library — or from Figma

Prebuilt React Email components on a drag-and-drop canvas. When Figma has something new, paste desktop + mobile frame links, build with react.email primitives, then customize styles in the tool.

Core idea

Two ways to build an email

Reuse what’s already in the registry, or bring a new Figma design in when the library doesn’t have it yet.

Figma import

From Figma link to canvas block

Desktop and mobile frame URLs → design context → build using React Email (react.email/components) → drop onto the email canvas.

Email-client reality

Choose: React component or image

Many CSS styles break in Outlook and other clients. When a Figma layout can’t be rebuilt safely in HTML, export the frame as an image and embed it. You pick this when adding a Figma link.

Prefer React when possible Fall back to image for client-safe fidelity
Scale

Build multiple components at once

Add several Figma component links in one batch run. Each link is fetched and built into a React Email (or image) block and added to the canvas — no one-by-one busywork.

Human in the loop

Customize after import

Automated builds are a strong starting point — not the finish line. Fix spacing, typography, colors, and content in the tool when something doesn’t look right in email.
