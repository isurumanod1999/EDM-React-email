- (decision) Use a neutral multi-client enterprise product identity; do not imply official Nissan branding without approved assets.
- (decision) Redesign the complete application shell, home, workspace, editor, menus, dialogs, states, and responsive behavior while preserving every working feature and API contract.
- (decision) Use Adobe Campaign only as an enterprise maturity and workflow-density benchmark, never as a visual clone.
- (decision) Both light and dark modes must feel deliberately designed; light mode must not appear as undifferentiated plain white.
- (event) Sources confirmed by continuation: product PRD, builder polish backlog, and demo presentation pack.
- (assumption) Desktop and laptop are the primary operator surfaces; tablet and mobile retain the same IA through drawers and compact command bars.
- (assumption) Adopt a stable global product shell plus a distinct document command bar; group commands by Navigate, Create/Import, Review, and Deliver instead of showing equal-weight buttons.
- (assumption) Use comfortable-dense operator spacing for chrome and inspectors while keeping the email canvas visually spacious.
- (assumption) Use named surface layers in both themes: product chrome, workspace pasteboard, panel, raised control, overlay, and content-true preview frame.
- (assumption) All existing gallery, import, tagging, code, preview, save, export, send, reusable-component, accessibility, and responsive behaviors are regression contracts.
