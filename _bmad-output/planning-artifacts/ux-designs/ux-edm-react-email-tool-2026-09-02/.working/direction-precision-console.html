Direction A

Precision Console

The editor reads as an instrument panel: hairline rules carry all structure, radii stay near zero, and every command sits inside a labelled group (Import, Review, Deliver) so the document bar can be scanned rather than read. Metadata is tabular and monospaced, and a persistent status strip keeps autosave, block count, and render state visible without opening anything. Density is deliberately tight so an operator working ten campaigns a day never scrolls chrome to reach a control.
