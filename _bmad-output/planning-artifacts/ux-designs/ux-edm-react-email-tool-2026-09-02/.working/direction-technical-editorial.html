Direction D

Technical Editorial

This direction treats the template as a typeset document. Serif headings and numbered command sections replace button clusters, rules and dotted leaders replace panels, and every identifier — component id, hex, URL — is set in monospace so values read as data rather than prose. The block list and the insert list are merged into one left-hand document column, which frees the centre for a preview at near-mail width and gives the screen an unusually calm reading order for a tool this dense.
